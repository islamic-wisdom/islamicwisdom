Put the Noori Nastaleeq font here so every visitor sees it:

  fonts/jameel-noori-nastaleeq.woff2   (preferred, smaller)
  fonts/jameel-noori-nastaleeq.ttf     (also fine on its own)

index.html already points at these names. Until a file is here, visitors who have
Jameel Noori Nastaleeq installed on their device still see it; everyone else sees
Noto Nastaliq Urdu instead.

Check the font's licence allows web use before adding it to this public repo.
